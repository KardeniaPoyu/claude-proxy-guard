# Security

Experimental Windows network guard; not an account-ban prevention tool or security sandbox.

Please report security issues through GitHub private vulnerability reporting when available. Never attach tokens, full proxy configurations, private IP inventories or personal logs. If private reporting is unavailable, open an issue requesting a private contact without exploit details or secrets.

Threat model and limitations are in README.md. Administrators, same-user malicious code, unlisted child executables, Windows delegated DNS, proxy fallback behavior and existing connections are outside the claimed boundary.
